    Benchmark
    
    Four tools. Same pages. Real tokens.
    
    
    We ran WhittleBrowser, Playwright MCP, browser-use and Stagehand on the same 11 pages (5 test pages and 6 live sites) with the same Chromium, and counted exactly what each one puts in front of the model. No LLM calls, so nothing is estimated except screenshot tokens.
    
  
    
  
  
  
  
  
    
    
    Same pages, same browser
    Every tool loads the same 11 URLs in the same Chromium build at 1280×860. Fixture pages are served locally so results are repeatable.
    
    
    Each tool's own code
    Playwright's ariaSnapshot (what Playwright MCP returns), browser-use's AgentMessagePrompt, Stagehand's page.snapshot() and its act prompt builders. Nothing re-implemented.
    
    
    Exact text, counted
    We capture the exact text each tool builds and count it with the o200k tokenizer. Run it yourself: pnpm bench -- --live --pw-mcp. Full methodology →

    #PageDigest
    
    
    
  
    

    



    
  
    
    Works on real-world markup
    
    Div soup in. A clean page out.
    
    
    Most modern apps are <div>s with click handlers: no buttons, no nav, no header tags, modals built from overlays. WhittleBrowser finds the real handlers (including React onClick props) and infers headers, sidebars, footers, menus and dialogs from layout and naming. The model sees a page it can act on.

    Safety model
    
    Pages are hostile. Your secrets stay home.
    
  
    
  
    
    
    AI off by default
    Off, Ask or Allowed per site. Nothing is sent from sites you haven't allowed.
    
    
    Auto-pause
    Banks, cloud consoles, password managers and card/ID/API-key fields pause AI automatically.
    
    
    Secrets never leave
    Field values are masked in the page. Keys and cards become ‹tokens›. Vault refs are typed locally.
    
    
    Injection shield
    Hidden text is dropped before the model sees the page. Instruction-like text is flagged.
    
    
    Approvals
    Pay, delete, send, publish, cross-site data jumps and uploads need your OK.
    
    
    Isolated agent
    Runs in a CDP isolated world, so page scripts can't tamper with what it sees.
    
    
    Honest identity
    UA token, Web Bot Auth signatures (verified with Cloudflare's checker), robots.txt. No spoofing, no CAPTCHA solving.
    
    
    Auditable
    The in-page agent, the privacy filter and the leak tests are MIT-licensed source you can read.
