Ghost cursor · live steps

Watch it work. Stop it any time.

Before every click or keystroke, a cursor glides to the target, a ring highlights it, and a caption says what's about to happen. The Agent panel streams each step, and every entry expands to show exactly what was sent to the model and how many tokens it cost.

  • Risky actions (pay, delete, send, publish) wait for your click
  • CAPTCHAs and 2FA are handed to you, then the agent resumes
  • One click turns AI off for a site
Built-in chat · ⌘⇧A

Your Claude or Codex, right in the browser.

Ask about the page or hand the agent a task. The chat runs on the Claude Code or Codex CLI you're already signed into, so there are no API keys and no extra bill. Every turn goes through the same gates: the AI dot, auto-pause and your approvals.

  • Pick Claude Code or Codex per conversation
  • Only the browser tools are allowed: no shell, no file access
  • Savings meter: tokens sent vs saved, live
  • Start page with example tasks and lifetime stats
Demo Studio · ⌘⇧R

Record once. Ship a polished demo.

Hit record, then use the page yourself or let the agent work. The Studio turns the capture into a product video: the camera eases into every click, captions come from the agent's steps, idle time speeds up, and the window sits on a gradient with intro and outro cards. Export WebM or MP4.

  • Auto-zoom, click ripples, smooth cursor
  • Captions straight from agent steps
  • Human-like cursor paths and typing for natural-looking runs
